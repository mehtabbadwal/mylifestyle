# Life + Āyur — Personal Lifestyle Medicine × Ayurveda Guide

A personalized PWA (Progressive Web App) combining Lifestyle Medicine and Ayurveda principles. Designed for iPhone home screen pinning.

## Deploy to GitHub Pages (5 minutes)

### Step 1: Create Repository
1. Go to [github.com/new](https://github.com/new)
2. Name it `life-ayur-guide` (or whatever you want)
3. Set to **Private** (this is personal health data)
4. Click **Create repository**

### Step 2: Upload Files
1. Click **"uploading an existing file"** link on the empty repo page
2. Drag both `index.html` and `manifest.json` into the upload area
3. Click **Commit changes**

### Step 3: Enable GitHub Pages
1. Go to **Settings** → **Pages** (left sidebar)
2. Under **Source**, select **Deploy from a branch**
3. Under **Branch**, select **main** and **/ (root)**
4. Click **Save**
5. Wait 1-2 minutes — your site will be live at: `https://YOUR-USERNAME.github.io/life-ayur-guide/`

### Step 4: Add to iPhone Home Screen
1. Open the GitHub Pages URL in **Safari** on your iPhone
2. Tap the **Share button** (square with arrow)
3. Scroll down and tap **"Add to Home Screen"**
4. Name it **"Life + Āyur"** (or whatever you want)
5. Tap **Add**

The app will now appear on your home screen with its own icon. It opens full-screen without Safari's address bar — looks and feels like a native app.

## Updating the Guide
When the guide is updated:
1. Go to your repository on GitHub
2. Click on `index.html`
3. Click the **pencil icon** (Edit)
4. Replace all content with the new file
5. Click **Commit changes**
6. GitHub Pages auto-deploys in ~1 minute
7. The app on your home screen updates automatically next time you open it
